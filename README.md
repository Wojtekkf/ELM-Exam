# Quiz ELM.04

Quiz do nauki do egzaminu zawodowego ELM.04 (montaż, uruchamianie i konserwacja układów automatyki przemysłowej).

- 113 unikalnych pytań z objaśnieniami
- tryb ćwiczenia (od razu widać poprawną odpowiedź) i tryb egzaminu (wynik na końcu)
- egzaminy po 40 pytań bez powtórzeń: pytanie użyte w jednym egzaminie nie wraca w następnym
- historia wyników i użytych pytań zapisuje się w przeglądarce (localStorage)

## Uruchomienie lokalnie

Otwórz `index.html` w przeglądarce. Nie wymaga serwera ani instalacji.

## Publikacja na GitHub Pages

1. Utwórz repozytorium i wrzuć pliki `index.html`, `.nojekyll` i `README.md`.
2. Settings → Pages → Source: „Deploy from a branch”, branch `main`, folder `/ (root)`.
3. Po chwili quiz będzie pod adresem `https://TWOJA-NAZWA.github.io/NAZWA-REPO/`.
